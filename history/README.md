# history/ — 과거 데이터와 분석 도구

미국 주식 과거 데이터(Massive, 예전 이름 Polygon.io)를 받아 두고, 전략을 백테스트하는 폴더예요.
분석은 전부 **`analyze.py` 하나로** 해요. 파이썬 3.9 이상이면 되고, 추가로 설치할 패키지는 없어요.

## 빠른 시작

프로젝트 폴더(`C:\Projects\toss-bot`)에서 실행해요. `python`이 안 되면 `py`로 바꿔 보거나 Anaconda Prompt에서 실행하세요.

```
python history/analyze.py status                                   # 데이터 현황
python history/analyze.py orb --stop 0.1,0.25,0.5,1.0 --split 2026-02-01   # 5분 시가범위 돌파, 손절폭 4가지
python history/analyze.py f --split 2026-02-01                     # F(VWAP 아래 눌림)
python history/analyze.py f --set tp=0.16 sl=0.08 hold=180 --name F_16_8_180   # F 설정 바꿔서
python history/analyze.py gainers --split 2026-02-01               # 조사한 6가지 전략
python history/analyze.py hold                                     # 급등주를 며칠 들고 가면?
python history/analyze.py after --split 2026-02-01                 # 급등주 종가 매수 → 애프터장 19:50 매도
python history/analyze.py report orb --split 2026-02-01 --by price # 저장된 결과를 다시 요약 (가격대별)
python history/pack_sip.py 2024-12 2025-01 ...                     # 규칙 찾기 준비: 분봉을 달마다 data/pack/sip_YYYY-MM.npz로 묶음
python history/mine/run.py                                          # 규칙 찾기 전체 (약 3~5분, numpy·scikit-learn 필요)
python history/mine/run.py search_intra val_intra                   # 원하는 단계만
python history/pack_gap.py 30 && python history/mine/run.py gap     # 갭상승 급등주(프리장 정보) 규칙 찾기
```

- **공통 옵션:** `--from 2025-01-01 --to 2025-12-31`(기간), `--workers 4`(동시에 쓸 코어 수, 기본은 코어 수-1), `--name 이름`(결과 이름), `--fresh`(처음부터 다시)
- **이어서 계산:** 결과는 `results/<이름>/<날짜>.json`에 날짜별로 저장돼요. 중간에 꺼도 다시 실행하면 이어서 해요.
- **설정 섞임 방지:** 같은 이름으로 설정만 바꿔 돌리면 멈춰요. `--name`을 새로 주거나 `--fresh`를 붙이세요.
- **`report` 옵션:**
  - `--split 날짜`: 그 날짜 전과 후를 나눠 보여 줘요. 한쪽에서 찾고 다른 쪽에서 확인하는 용도예요.
  - `--cost 0.5,1,2`: 스프레드·미끄러짐 배수별 결과예요. 시가범위 돌파만 돼요.
  - `--by month|price|time`: 월별, 가격대별, 개장 후 시간대별로 나눠 봐요.
  - `--bot`: F를 실제 봇처럼 동시 3개, 하루 15회로 제한해서 봐요.
- **걸리는 시간 (대략):** 시가범위 돌파 2년치는 코어 하나로 30분 정도예요. 작업자 4~7개면 5~10분이에요. `status`와 `hold`는 1분 안에 끝나요.

## 결과 읽는 법

- 수익률은 **비용(스프레드 + 수수료 0.1%씩 + 미끄러짐)을 뺀 거래당 평균**이에요. "비용 전"은 비용을 빼기 전이에요.
- **t값:** ±2를 넘으면 우연으로 보기 어려워요. 여러 설정을 시험해서 고른 규칙이면 **+3 이상**이어야 믿을 만해요 (Harvey·Liu·Zhu 2016).
- **판단 순서:**
  1. 앞 기간(예: 2024-12~2026-01)에서만 고르고, 뒤 기간(2026-02~11)에서 그대로 확인해요.
  2. 시험할 설정 수는 미리 정해서 적게 해요.
  3. 큰 수익 상위 2%를 빼도 플러스인지 봐요.
  4. 월별로 절반 넘게 플러스인지 봐요.

### 규칙 찾기 (`mine/`, 2026-11-20)

|---|---|---|---|
| 당일매매 규칙 490만 개 (갭 ±2% 종목 43,290건) | 최고 +1.31%/거래 (t=3.3) — 490만 개 중 이 정도는 우연으로도 나옴 | 상위 100개 중 플러스 21%, 평균 -0.19%, t>2 없음 | 시험할 후보 없음 |

| 며칠 보유 규칙 75만 개 (종가 $3~25, 47만 건) | 10일 보유는 거의 다 플러스 (그냥 다 사도 +0.83%) | 다 사기 대비 나은 비율 50% | 미리 정한 3개 모두 손해: -1.79%, -1.66%, -1.38% (다 사기 -1.36%) |

- **결론: 수익이 '났던' 규칙은 많지만, 다음 기간에도 난 규칙은 없어요.** 며칠 보유가 벌었던 건 2025년 소형주 상승장 덕분이에요. 2026-05~11에 소형주가 빠지자 같이 잃었어요.
- **미래 정보 실수 주의:** 처음에 '첫 30분 수익률'을 10:00 전 진입에도 썼더니 +2~4%/거래 규칙이 수천 개 나왔고 확인 기간도 100% 통과했어요. 미래 정보는 두 기간에 똑같이 들어가서 기간 나누기로는 안 걸러져요. 진입 시점에 알 수 있는 값만 쓰도록 고친 뒤의 결과가 위 표예요.
- 비용: 수수료 0.1%씩 + 매도 0.03%, 스프레드 max(2센트, 0.1%), 돌파 미끄러짐 0.1%, 손절 미끄러짐 0.3%. t값은 같은 날 거래를 묶어서 계산(며칠 보유는 겹침 보정 Newey-West).
- **하따 (`mine/hatta.py`, 크게 빠진 종목 매수):** 전일 대비 -15~-50% 지정가 매수 또는 종가 매수 × 청산 5가지(당일 종가~5일 뒤), 45개. **전부 손해.** 많이 빠질수록, 오래 들고 있을수록 더 잃음 (-50% 지정가 → 5일 뒤 찾기 -17.8%, 확인 -26.5%). 비용 전에 플러스인 건 '종가 -20~30% 매수 → 다음 날 시가 매도'(밤사이 반등 +1~2%)뿐인데, 스프레드 0.8%를 빼면 확인 기간 -1~-2%.
- **갭상승 급등주 + 프리장 정보 (`mine/*_gap.py`):** 시가 +15%↑·시가 $1~10, 그날 분봉을 빠짐없이 받은 346일만 (안 받은 종목은 대부분 시가 뒤 -6~-9% 빠진 종목이라 다 쓰면 부풀려짐), 2,699건. 진입 17 × 청산 16 × 프리장 거래대금·프리장 고가 대비 시가·프리장 막판 흐름 등 29개 특징 조건 1~2개 = 456만 개, 거래당 ±50%로 잘라 계산.
  - 찾기 상위 3,000개 중 확인 기간 플러스 41~47%. 두 기간 모두 t>2인 8개를 최종 기간에 한 번 시험 → 플러스 4개, t>2 0개, 평균 -0.64%.
  - 기계학습 272개: 예측 상위 20%가 '전부 매매'보다 나은 경우 75% (고르는 힘은 조금 있음), 그래도 비용 뺀 뒤 플러스 33%, 평균 -0.65%.
  - 본전에 가장 가까운 것: 시가보다 5~15% 싸게 지정가 매수 + 목표 +5%/손절 -3% → 세 기간 모두 거래당 -0.7~+0.8% 사이(대부분 0 근처). 지정가라 스프레드를 덜 내서 다른 방식(-1~-4%)보다 훨씬 덜 잃음.
  - **실전 반영 (2026-11-20~, `orb/gap_dip.mjs`):** 지정가 조합 18개를 2년 전체로 비교해 고른 '시가 $1~3, 시가 -5% 지정가, 목표 +10%/손절 -5%' → 1,148건 거래당 +0.94% (t=3.4), 찾기 +0.99%·확인 +0.42%·최종 +1.33%, 비용 1.5배 +0.70%. 18개 중 고른 것이라 실전 결과로 다시 확인해야 함.
  - 청산 방식 비교 (`mine/exit_variants_gap.py`): +10% 전부 매도 +0.97% > 반만 팔고 나머지 +20% +0.70% > +10% 뒤 추적 손절 +0.71% > +15% +0.84% > +20% +0.53% > 반만 팔고 본전 손절 +0.28% > 목표 없이 마감까지 -0.79%. 반등은 짧고 다시 빠지는 경우가 많아서 +10%에서 다 파는 게 가장 나음.
- 한계: 일봉 파일에 저가 $30 넘는 종목이 없어서 SPY 대신 SCHB를 시장 지표로 씀. 며칠 보유 후보의 종목 종류(레버리지 ETF 여부)는 67%만 알고 나머지는 남겨 둠.

- 시가범위 돌파는 비용 전 수익이 통계적으로 뚜렷해요. 논문 결과가 2024~2026 데이터에서도 재현된 셈이에요. 하지만 토스 비용(왕복 약 0.8%)을 넘지 못해요.
- 급등 잡주를 사는 전략은 비용 전부터 수익이 거의 없어요.
- 애프터장은 스프레드가 정규장의 두 배(토스 실측 중간값 1.62%)예요. 급등주는 종가 뒤에 오히려 더 빠졌어요. 당일 +100% 넘게 오른 종목은 비용 전 -5.0%였어요.
- **프리장 전략은 이 데이터로 공정하게 시험할 수 없어요.** Massive 일봉 고가가 정규장 기준이라 급등일 목록엔 '정규장에서도 +15% 오른 날'만 있어요. 프리장에 올랐다 꺼진 종목이 빠져서 결과가 부풀려져요. 제대로 하려면 전 종목 분봉(프리·애프터 포함)이 필요해요. Massive 유료 Starter의 flat files로 받을 수 있어요.
